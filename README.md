# WebKasir — Kasir Kebab Pribadi

Aplikasi kasir berbasis web untuk memudahkan pencatatan pesanan kebab saat berjualan.

🔗 **Live:** https://jrieee.github.io/kasir-kebab/

## Fitur
- 🌯 35+ menu kebab, burger & tambahan dengan harga lengkap
- 🧾 Multi-pesanan antrian (Pesanan #1, #2, dst.) — banyak pelanggan bersamaan
- 🌶️ Pilihan varian: Rasa (Saos Tomat / Sedang / Pedas) & Sayur (Lengkap / No Sayur)
- 💵📱 Metode bayar: Cash (hitung kembalian otomatis) atau QR/QRIS
- 📊 Histori penjualan per hari (7 hari) dengan breakdown Cash vs QR
- 📥 Export rekap harian ke Excel (.csv)
- 📱 Kompatibel HP & desktop, dark mode
- 💾 Data tersimpan otomatis (LocalStorage browser)

## Cara Pakai
Buka di browser — tidak perlu install apapun.
